# @uikey/svelte-generator

This package provides a direct generator for Svelte components from UIKey extracted DOM trees.

## Installation

\`\`\`bash
npm install @uikey/svelte-generator
\`\`\`

## Usage

You can use the \`generateSvelteFile\` function to recursively traverse a UIKey node tree and output a standard \`.svelte\` file string containing script, markup, and style blocks.

\`\`\`typescript
import { generateSvelteFile } from '@uikey/svelte-generator/src/generate';
// or wherever it is exported depending on your build setup

// Example uiTree and designTokens extracted by @uikey/extractor
const uiTree = { ... }; 
const designTokens = {
  colors: {
    "color-1": "rgba(255, 255, 255, 1)",
    "color-2": "rgba(0, 0, 0, 1)"
  },
  fonts: {
    "size-1": "16px"
  }
};

const svelteString = generateSvelteFile(uiTree, designTokens);

console.log(svelteString);
/*
Output looks like:
<script lang="ts">
  // Generated by UIKey Svelte Generator
</script>

<div class="bg-color-1 text-color-2">
  Hello World
</div>

<style>
</style>
*/
\`\`\`
