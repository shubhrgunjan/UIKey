# @uikey/vue-generator

This package provides a direct generator for Vue Single File Components (SFC) from UIKey extracted DOM trees.

## Installation

\`\`\`bash
npm install @uikey/vue-generator
\`\`\`

## Usage

You can use the \`generateVueSFC\` function to recursively traverse a UIKey node tree and output a raw Vue Single File Component string.

\`\`\`typescript
import { generateVueSFC } from '@uikey/vue-generator/src/generate';
// or wherever it is exported depending on your build setup

// Example uiTree and designTokens extracted by @uikey/extractor
const uiTree = { ... }; 
const designTokens = {
  colors: {
    "color-1": "rgba(255, 255, 255, 1)",
    "color-2": "rgba(0, 0, 0, 1)"
  },
  fonts: {
    "size-1": "16px"
  }
};

const sfcString = generateVueSFC(uiTree, designTokens);

console.log(sfcString);
/*
Output looks like:
<template>
  <div class="bg-color-1 text-color-2">
    Hello World
  </div>
</template>

<script setup lang="ts">
// Generated by UIKey Vue Generator
</script>

<style scoped>
</style>
*/
\`\`\`
